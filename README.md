# Global Solution — FIAP | Fase 3

Repositório do projeto Global Solution da Fase 3 de Ciências da Computação.

O tema, os requisitos e as tecnologias serão definidos a partir do enunciado da atividade.

## Estrutura

- `src/`: código-fonte do projeto.
- `tests/`: testes e cenários de validação.
- `docs/`: enunciado, planejamento e documentação técnica.
- `dados/`: dados de exemplo usados no projeto.
- `entregas/`: relatórios, apresentações e arquivos finais.

## Próximos passos

1. Adicionar o enunciado em `docs/`.
2. Registrar integrantes, requisitos e prazos.
3. Definir as tecnologias e as instruções de execução.
